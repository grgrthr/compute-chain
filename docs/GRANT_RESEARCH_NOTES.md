# Compute Chain — Grant Research Notes

## A. Filecoin Official Findings

- Program: Filecoin Foundation Open Grant
- URL: https://fil.org/grants/
- Status: Rolling applications — no fixed deadline
- Eligibility: Open-source projects building on Filecoin/IPFS
- Process: Online application form
- Review: Not publicly detailed — likely includes technical review
- Interview: Not verified from official source
- Funding range: No published minimum/maximum — $30,000 is within typical range
- License: Open source required
- Fit: Compute Chain CID integration is a plausible future milestone; no current Filecoin code exists

## B. NLnet Official Findings

- Program: NGI Zero Commons Fund
- URL: https://nlnet.nl/commons/
- Status: Active — check website for current call deadlines
- Eligibility: Individuals and organizations; open-source projects
- Geographic: European/international — check current call for restrictions
- Process: Online application + possible interview
- Funding: EUR 5,000 to EUR 50,000 typical range
- License: Open source required (MIT compatible)
- Duration: Typically up to 12 months
- Fit: Verifiable compute as open digital infrastructure matches NGI Zero priorities

## C. Eligibility Analysis

- Both programs accept individual applicants
- Both require open-source licensing (MIT qualifies)
- No previous funding requirement found
- No incorporation requirement found

## D. Application Process

- Both accept written online applications
- NLnet may request an interview — not guaranteed
- Filecoin process is less publicly documented

## E. Communication/Interview

- NLnet: Possible interview, not always required
- Filecoin: Not verified — assume possible

## F. Funding Limits

- Filecoin: No published limit — $30,000 is typical
- NLnet: EUR 5,000-50,000 typical; EUR 40,000 within range

## G. Deadline Status

- Filecoin: Rolling — apply anytime
- NLnet: Periodic calls — check https://nlnet.nl/commons/ for current deadline

## H. Fit Assessment

- Filecoin: Good conceptual fit but requires integration work that does not yet exist
- NLnet: Strong fit — verifiable compute as open infrastructure aligns with NGI Zero mission

## I. Risks

- Filecoin: No existing Filecoin integration code
- NLnet: May require European connection or coordinator
- Both: Single-node prototype needs multi-worker hardening

## J. Open Questions

- Filecoin: Exact review criteria not publicly documented
- NLnet: Current call deadline must be verified
- Both: Whether solo developer without organization is eligible (likely yes, not confirmed)
